## 📖 项目简介

本项目是一个 **JavaScript 逆向工程实战案例库**，收录了多个真实平台的加密参数分析与还原过程。

每个案例独立成目录，记录了从**接口定位 → 加密参数识别 → 算法还原 → 采集实现**的完整链路。案例之间互不依赖，可单独阅读与参考。

> **声明**：本项目仅供学习研究与技术交流使用，不得用于任何商业用途或非法用途。所有案例均针对公开可访问的接口进行分析，不涉及任何用户隐私数据采集。
